# Bank_Loan_Interactive_Excel_Dashboard

🏦 Bank Loan Report -

An interactive Bank Loan Analysis project developed in Microsoft Excel to transform 38,576 loan records across 24 attributes into meaningful KPIs, performance reports, and interactive visualizations.

📊 Project Overview

The project includes two interactive dashboards designed for different levels of loan analysis:

1️⃣ Summary Dashboard — Loan Performance
The Summary Dashboard provides a consolidated view of overall loan performance through key financial and operational KPIs.
Key Metrics:

.Total Loan Applications: 38.6K
.Total Funded Amount: $435.8M
.Total Amount Received: $473.1M
.Average Interest Rate: 12.05%
.Average DTI: 13.33%
.Good Loan Applications: 86.18%
.Analysis includes:
.Good vs. Bad Loan performance
.Loan applications by status
.Funded amount and amount received by loan status
.Monthly-to-Date (MTD) performance
.Month-over-Month (MoM) changes
.Interactive filtering by loan grade and purpose

2️⃣ Overview Dashboard — Trends & Borrower Analysis

The Overview Dashboard provides a deeper view of loan applications and borrower characteristics.
Analysis includes:

.Monthly loan application trends
.State-wise distribution of loan applications
.36-month vs. 60-month loan terms
.Applications by employment length
.Loan applications by purpose
.Home ownership analysis
.Loan status distribution

This dashboard helps identify application trends, borrower profiles, loan preferences, and geographical patterns within the dataset.

🛠️ Tools & Techniques:

.Microsoft Excel
.Pivot Tables & Pivot Charts
.Power Query for data preparation and transformation
.Power Pivot for data modeling
.Slicers & interactive filters
.KPI reporting
.Data cleaning
.Data visualization
.MTD & MoM analysis

📁 Workbook Structure

The complete Excel workbook contains:

.Raw Data → Pivot Tables → Summary Dashboard → Overview Dashboard
.The project demonstrates an end-to-end workflow of data preparation, analysis, KPI development, and interactive dashboard creation in Excel.
